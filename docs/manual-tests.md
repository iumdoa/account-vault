## 3. Section 12 MVP 22 项验收矩阵逐项核验结果

### 1. [x] 全新数据目录可创建账号库，重启后用主密码解锁
- **操作步骤**：
  1. 清空临时测试目录，调用 `controller.initialize()`，系统进入 `uninitialized` 状态；
  2. 呈现 `CreateVaultView`，输入合法主密码（如 `MasterPassword!123`）及确认密码，点击“创建主密码库”；
  3. 系统调用 `repository.createVault` 生成主库文件 `vault.avlt`，自动进入 `unlocked` 状态；
  4. 重启应用（销毁当前 Controller 并重新初始化），系统检测到存在 `vault.avlt` 进入 `locked` 状态；
  5. 呈现 `UnlockView`，输入原主密码触发解锁。
- **实际结果**：成功完成 Argon2id 密钥派生并加载凭据库，状态变为 `unlocked`，测试套件 `stage3_integration_test.dart` 及实机验证通过。

### 2. [x] 错误主密码不破坏文件；不存在静默重置账号库逻辑
- **操作步骤**：
  1. 对现有已初始化的 `vault.avlt` 计算 SHA-256 校验和及文件长度；
  2. 在解锁界面连续 5 次输入错误主密码；
  3. 观察界面反馈，并重新比对磁盘文件状态。
- **实际结果**：
  - 每次错误输入均被捕获为 `AuthenticationFailedException`，界面显式提示“主密码错误，请重新输入”，输入框自动聚焦并清空；
  - 磁盘上的 `vault.avlt` 文件 SHA-256 校验和与修改时间完全未变，绝不修改、覆盖或静默重置现有账号库。
